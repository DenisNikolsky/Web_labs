# To-Do List

Веб-приложение для управления задачами, разработанное в рамках лабораторной работы. Реализовано на JavaScript с использованием **DOM API** - без единого фреймворка и без единой строки разметки в HTML-файле.

**Демо:** [https://DenisNikolsky.github.io/todo-list/](https://DenisNikolsky.github.io/todo-list/)  
**Репозиторий:** [https://github.com/DenisNikolsky/todo-list](https://github.com/DenisNikolsky/todo-list)

---

## О проекте

To-Do List - это SPA-приложение, в котором пользователь может:

- создавать задачи с названием и датой;
- редактировать текст и дату существующих задач;
- удалять задачи;
- отмечать задачи как выполненные (с визуальным изменением);
- искать задачи по названию;
- фильтровать задачи по статусу (все / выполненные / невыполненные);
- сортировать задачи по дате (по возрастанию / по убыванию);
- менять порядок задач с помощью **drag-and-drop**;
- сохранять состояние в `localStorage` и восстанавливать его при перезагрузке страницы.

## Технологический стек

| Технология | Назначение |
|---|---|
| **HTML5** | Минимальный каркас документа + подключение скрипта |
| **CSS3** | Стили (Flexbox, media queries), инжектируются через `document.createElement('style')` |
| **JavaScript (ES6+)** | Вся разметка, стили и логика приложения через DOM API |
| **Web Storage API** | `localStorage` для персистентного хранения задач |
| **HTML5 Drag & Drop API** | Перестановка задач в списке |

## Архитектура

Проект состоит из двух файлов:

```
todo-list/
├── index.html     # только каркас + <script src="script.js">
└── script.js      # вся разметка, стили и логика
```

### `index.html`

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>To-Do List</title>
</head>
<body>
  <script src="script.js"></script>
</body>
</html>
```

Внутри `<body>` нет ни одного элемента, кроме подключения скрипта - вся структура страницы создаётся программно через `document.createElement` и `append`.

### `script.js` - структура модуля

```
injectStyles()      - динамическая инжекция всех CSS-стилей
loadTasks()         - восстановление задач из localStorage
saveTasks()         - сохранение задач в localStorage
generateId()        - генерация уникального ID
formatDate()        - форматирование ISO-даты в DD.MM.YYYY
buildApp()          - построение всей структуры страницы
handleAdd()         - добавление новой задачи
deleteTask()        - удаление задачи по ID
getVisibleTasks()   - фильтрация + поиск + сортировка
render()            - перерисовка списка задач
createTaskElement() - создание <li> для одной задачи
buildEditView()     - режим редактирования задачи
handleDragStart/Over/End/Drop - drag-and-drop
```

## Реализованный функционал

### 1. Добавление задачи
Форма с полями **название** (обязательное) и **дата** (опциональное). По `submit` создаётся объект задачи и добавляется в массив `tasks`, затем вызывается `saveTasks()` и `render()`.

### 2. Удаление задачи
Кнопка удаляет задачу из массива по `id` и перерисовывает список.

### 3. Редактирование задачи
Кнопка переключает задачу в режим редактирования: появляются два `input` (название, дата) и кнопки (сохранить) / ✖️ (отмена). Поддерживаются клавиши **Enter** (сохранить) и **Escape** (отмена).

### 4. Отметка «выполнено»
Чекбокс переключает флаг `done`. Задача получает класс `task-item--done`, текст становится зачёркнутым, фон - зелёным.

### 5. Поиск по названию
Поле `input[type="search"]` фильтрует задачи по подстроке (регистронезависимо) в `title`.

### 6. Фильтрация по статусу
`select` с опциями: **Все / Выполненные / Невыполненные**.

### 7. Сортировка по дате
`select` с опциями: **Без сортировки / По дате ↑ / По дате ↓**. Задачи без даты уходят в конец при сортировке по возрастанию.

### 8. Drag-and-drop
Каждый `<li>` имеет атрибут `draggable="true"`. При перетаскивании:
- `dragstart` запоминает `id` задачи;
- `dragover` подсвечивает элемент-цель;
- `drop` переставляет задачу в массиве `tasks` (через `splice`), сохраняет и перерисовывает.

### 9. Сохранение в localStorage
Каждое изменение (добавление, удаление, редактирование, изменение статуса, перестановка) вызывает `saveTasks()`, который сериализует массив в JSON. При загрузке страницы `loadTasks()` восстанавливает данные.

### 10. Адаптивность
Flexbox-раскладка + `@media (max-width: 560px)`: поля формы и элементы управления растягиваются на всю ширину, уменьшаются отступы.

## Запуск проекта локально

```bash
git clone https://github.com/DenisNikolsky/todo-list.git
cd todo-list
```

Так как проект не использует сборщиков и модулей, достаточно открыть `index.html` в браузере. Для корректной работы `localStorage` рекомендуется запустить локальный сервер:

```bash
# Python 3
python -m http.server 8080

# или Node.js
npx serve
```

Затем открыть [http://localhost:8080](http://localhost:8080).

Проект задеплоен через **GitHub Pages**:

[https://DenisNikolsky.github.io/todo-list/](https://DenisNikolsky.github.io/todo-list/)

**Как задеплоить самостоятельно:**
1. Запушьте файлы `index.html` и `script.js` в ветку `main`.
2. Откройте **Settings → Pages**.
3. В разделе **Source** выберите Branch: `main`, папка `/ (root)`.
4. Нажмите **Save** - через ~1 минуту сайт станет доступен по ссылке.
